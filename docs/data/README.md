# CEP planning data

`cep-objectives.csv` and `usability-tasks.csv` are structured summaries of the Group 9 CEP report, “A Filling Recipe for Open Tables at Kellogg Ranch,” revised October 17, 2026. They describe the plan, not participant observations.

`usability-observations-template.csv` is deliberately header-only. Add de-identified observations when collected. Do not interpret an empty dataset as zero success. Use success_unassisted = 1 or 0, nonnegative time_seconds, and ease_rating from 1 to 5. Use exactly the task labels in usability-tasks.csv. No raw participant data or fabricated values are included.
